# Praca domowa: Testowanie z Mockito

## Ćwiczenie 7a: Koszyk z rabatem (podstawowe mockowanie)

**Czego się nauczysz:** `@Mock`, `@InjectMocks`, `when/thenReturn`, `verify`, `verifyNoInteractions`

**Scenariusz:** System koszyka zakupowego oblicza cenę końcową z rabatem. `ShoppingCartService` używa `ProductRepository` do pobrania cen i `DiscountService` do pobrania rabatu klienta. Obie zależności to interfejsy bez implementacji, więc w testach musisz je zastąpić mockami.

**Twoje zadanie:** przepisz poniższy kod produkcyjny do projektu i napisz klasę testową `ShoppingCartServiceTest`, która sprawdza metodę `calculateTotal()`. Nie zmieniaj kodu produkcyjnego.

### Zależności (Maven)

Do `pom.xml` dodaj w zakresie `test`:
- `org.junit.jupiter:junit-jupiter`
- `org.mockito:mockito-junit-jupiter`
- `org.assertj:assertj-core`

### ShoppingCartService.java (klasa, którą testujesz)

```java
package com.example.cart;

import java.util.List;

public class ShoppingCartService {

    private final ProductRepository productRepository;
    private final DiscountService discountService;

    public ShoppingCartService(ProductRepository productRepository,
                               DiscountService discountService) {
        this.productRepository = productRepository;
        this.discountService = discountService;
    }

    /**
     * Oblicza końcową cenę koszyka po rabacie.
     */
    public double calculateTotal(String customerId, List<CartItem> items) {
        if (items == null || items.isEmpty()) {
            throw new IllegalArgumentException("Koszyk nie może być pusty");
        }

        double subtotal = 0.0;
        for (CartItem item : items) {
            Product product = productRepository.findById(item.getProductId())
                .orElseThrow(() -> new ProductNotFoundException(item.getProductId()));
            subtotal += product.getPrice() * item.getQuantity();
        }

        double discount = discountService.getDiscountForCustomer(customerId);
        return subtotal * (1.0 - discount);
    }
}
```

## Jakich testów oczekujemy

Klasa `ShoppingCartServiceTest` z `@ExtendWith(MockitoExtension.class)` i `@DisplayName("ShoppingCartService - testy mockowania")`. Mocki: `ProductRepository` i `DiscountService` (`@Mock`), testowany obiekt: `ShoppingCartService` (`@InjectMocks`).

W klasie zagnieżdżonej `@Nested` z `@DisplayName("calculateTotal()")` napisz testy:

1. **Powinien obliczyć cenę dla jednego produktu bez rabatu**
2. **Powinien zastosować 10% rabatu dla klienta VIP**
3. **Powinien obliczyć cenę dla wielu produktów**
4. **Powinien rzucić wyjątek dla pustego koszyka**
5. **Powinien rzucić wyjątek gdy produkt nie istnieje**

Wskazówki:
- przy cenach po rabacie porównuj z tolerancją (`isCloseTo(..., within(0.01))`), bo `double` nie liczy dokładnie;
- w teście pustego koszyka sprawdź, że żaden mock nie został użyty (`verifyNoInteractions`);
- w teście brakującego produktu mock repozytorium ma zwrócić `Optional.empty()`, a komunikat wyjątku ma zawierać id produktu.
